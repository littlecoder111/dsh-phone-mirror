# Code of conduct

## Our commitment

We want participation in this project to be a respectful experience for
everyone, regardless of experience level, background, identity, or device.

## Expected behavior

- Be considerate and specific in technical discussion.
- Assume good faith; critique code and ideas, not people.
- Respect privacy: do not ask for or publish another person's device serials,
  screenshots, clipboard contents, file paths, or account details.
- Keep issues and pull requests on topic.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without permission.
- Deliberately disruptive behavior, spam, or bad-faith security reports.
- Using the project to control a device or access data without its owner's
  consent.

## Scope

This code applies in the repository's issues, pull requests, discussions and
other project spaces.

## Enforcement

Maintainers may edit, remove, or reject contributions and may temporarily or
permanently restrict participation for behavior that violates this code.
Reports can be sent through the repository's private maintainer contact or a
GitHub security advisory; please do not include sensitive personal data in a
public issue.

This document follows the spirit of the Contributor Covenant.
